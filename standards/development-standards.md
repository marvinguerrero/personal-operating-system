# Development Standards

## Core Principles

- Documentation-first development
- Reproducible environments
- Cloud-first architecture
- Security-conscious workflows
- AI-assisted development
- Maintainable systems over quick hacks
- Version-controlled operational changes

---

## Repository Standards

- Every project must include a README
- Every major decision should be documented
- Use clear folder structures
- Avoid unnecessary dependencies
- Keep environments lightweight

---

## AI Usage Standards

- AI assists implementation, not blind replacement for reasoning
- Prompts with long-term value should be documented
- Reusable workflows should become templates
- AI-generated code should be reviewed before production use

---

## Documentation Standards

- Infrastructure changes must be documented
- Operational procedures should be reproducible
- Naming should remain clean and consistent
- Avoid undocumented workflows

---

## Security Standards

- Use SSH authentication whenever possible
- Enable MFA on important services
- Never commit secrets or credentials
- Prefer environment variables for sensitive data

---

## Infrastructure Philosophy

- Lightweight local environments
- Heavy workloads delegated to cloud when possible
- Avoid unnecessary complexity
- Systems should remain portable and reproducible
