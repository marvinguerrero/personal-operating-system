# AI Workflow System

## Purpose

This document defines the operational workflows for using AI systems across:
- development
- architecture
- documentation
- automation
- business operations
- research
- governance

---

## Core AI Stack

| Tool | Primary Role |
|---|---|
| ChatGPT | Strategy, architecture, orchestration |
| Claude | Long-form reasoning and implementation |
| Cursor | AI-assisted development environment |
| GitHub | Version-controlled operational backbone |
| Obsidian | Knowledge management and operational memory |

---

## AI Usage Principles

- AI should accelerate workflows, not replace reasoning
- Outputs should be reviewed before production use
- Reusable prompts should be documented
- Long-term workflows should become templates
- AI-generated systems should remain maintainable

---

## Workflow Philosophy

### Documentation First
- Document before scaling
- Document infrastructure decisions
- Preserve operational continuity

### Reusability
- Convert repeated prompts into templates
- Build reusable workflows
- Standardize successful operational patterns

### Scalability
- Prefer systems over ad hoc execution
- Build processes that can evolve into teams later
- Design for portability and reproducibility
